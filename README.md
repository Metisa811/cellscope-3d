# CellScope 3D — Interactive Eukaryotic Animal-Cell Atlas

CellScope 3D is an interactive, web-based 3D scientific atlas of a generalized eukaryotic animal cell built with **Three.js**, **Vite**, and modular ES modules. It combines soft-lit 3D procedural ultrastructure on a studio white background with a claim-mapped peer-reviewed literature layer, multi-scale exploration, exploded-view and cross-section inspection modes, and interactive educational tools.
